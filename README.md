# Nextep MVP

Nextep is an AI Learning Engine. The MVP supports Coding and Information Processing Engineer content through one reusable learning engine.

## Run

```bash
streamlit run app.py
```

## Test

```bash
pytest
```

## Current Modules

- Coding
- Information Processing Engineer

## Engine Capabilities

- Learning Mode and Exam Mode
- AI Coaching
- XP, missions, review queue, reflection, thought profile, and learning DNA
